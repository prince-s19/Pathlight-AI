## ✨ Overview

**Pathlight** is an AI-powered web platform that helps students discover **internships, hackathons, scholarships, fellowships, research programs, and competitions** — all in one beautifully animated, glassmorphic interface.

It blends real job-board data (Adzuna), Google **Gemini AI**-curated opportunities, and a Supabase-backed account system so you can search, filter, bookmark, and track opportunities tailored to **India 🇮🇳** or **USA/Global 🇺🇸**.

> 🔗 **Live App:** **[pathlight-ai.vercel.app](https://pathlight-ai.vercel.app/)**
